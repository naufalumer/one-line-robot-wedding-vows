One line of wedding vows for a robot couple: a promise to love, honour, and never install an update on your partner while they sleep. Built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (one line, 123 characters).
